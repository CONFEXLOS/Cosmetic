# BeautyLink Africa 🌟

Une super-application africaine de beauté, cosmétique et bien-être.

## Vision

BeautyLink Africa permet à chaque personne de mieux comprendre son profil beauté, suivre son évolution, recevoir des conseils personnalisés, consulter des professionnels vérifiés, découvrir des contenus fiables et acheter progressivement les produits adaptés à ses besoins.

## Fonctionnalités MVP (Phase 1)

- ✅ Authentification e-mail + OAuth
- ✅ Beauty Passport & profil beauté
- ✅ Réseau social beauté
- ✅ Annuaire d'experts vérifiés
- ✅ Boutique avec filtres
- ✅ Care Cart (panier de routine évolutive)
- ✅ Checkout sandbox
- ✅ Dashboard consommateur
- ✅ Rappels personnalisables
- ✅ Assistant IA non-médical

## Architecture

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Supabase (Auth, PostgreSQL, Storage)
- PWA installable

## Installation

```bash
pnpm install
pnpm dev
```
